# MS3DH TRIPE — مزامنة Discord والحفظ التلقائي

## ماذا يحدث تلقائيًا؟
- عند فتح الموقع، يحاول جلب بيانات السيرفر والرتب والأعضاء من Discord عبر Netlify Functions.
- يعيد محاولة تحديث بيانات Discord كل 5 دقائق تقريبًا، وعند الرجوع إلى تبويب الموقع.
- يجلب قائمة الأعضاء على صفحات متتابعة (حتى 10,000 عضو لكل مزامنة بدل التوقف عند أول 1,000).
- يصنّف الإدارة العليا والإشراف والدعم حسب IDs الرتب المحددة، مع مطابقة أسماء احتياطية إذا لم تُحدد IDs.
- يحفظ محتوى الموقع اليدوي في Netlify Blobs عند إعداد مفتاح الإدارة، ويحدّث النسخة المشتركة للزوار كل 15 ثانية تقريبًا.
- تخصصات الفرق والأخبار والقوانين وغيرها من المحتوى اليدوي تبقى منفصلة عن بيانات Discord ولا تُستبدل بأسماء الرتب.

## متغيرات Netlify المطلوبة
من **Site configuration → Environment variables** أضف:

- `DISCORD_BOT_TOKEN` — توكن البوت (سرّي، لا تضعه في `index.html` ولا ترسله لأحد).
- `DISCORD_GUILD_ID` — ID السيرفر.
- `ROLE_LEADERSHIP_ID` — ID رتبة الإدارة العليا.
- `ROLE_MODERATION_ID` — ID رتبة الإشراف/المودريتور.
- `ROLE_SUPPORT_ID` — ID رتبة الدعم.
- `SITE_CONTENT_ADMIN_KEY` — مفتاح قوي وسري لحفظ تعديلات لوحة الإدارة المشتركة.

بعد تعديل متغيرات البيئة، أعد **Deploy** للموقع حتى تُطبّق القيم.

## إعداد Discord Developer Portal
1. افتح تطبيق البوت في Discord Developer Portal.
2. من **Bot → Privileged Gateway Intents** فعّل **Server Members Intent** إن كان متاحًا، ثم احفظ التغييرات.
3. تأكد أن البوت داخل السيرفر وأن لديه صلاحية الوصول للسيرفر. لا تشارك التوكن علنًا.

## الحفظ الدائم للمحتوى اليدوي
1. تأكد من رفع `netlify/functions/content.mjs` و`package.json` كما هما.
2. أضف `SITE_CONTENT_ADMIN_KEY` في Netlify وأعد النشر.
3. افتح الموقع من جهاز الإدارة وسجّل الدخول إلى لوحة الإدارة. عند أول حفظ، أدخل نفس قيمة المفتاح إذا طلبها الموقع.
4. البيانات القديمة المخزنة في `localStorage` على جهاز واحد لا يمكن أن تظهر على كل الأجهزة تلقائيًا قبل رفعها مرة واحدة إلى التخزين المشترك من جهازها الأصلي.

## إذا لم تظهر البيانات
افتح `https://YOUR-SITE.netlify.app/.netlify/functions/discord?action=overview` بعد استبدال الرابط برابط موقعك. ثم جرّب `https://YOUR-SITE.netlify.app/.netlify/functions/discord?action=members&limit=20`. إذا ظهر خطأ، راجع **Netlify → Functions → Logs**. لا ترسل توكن البوت في الصور أو المحادثات.

## متغيرات أخرى
إذا كنت تستخدم التقديمات أو الدعم أو MongoDB في بقية الوظائف، أبقِ المتغيرات التي تحتاجها تلك الوظائف مثل `MONGODB_URI`, `MONGODB_DB_NAME`, `APPLICATIONS_ADMIN_KEY`, و`SUPPORT_ADMIN_KEY`.
